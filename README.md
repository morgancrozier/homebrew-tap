# Morgancrozier Tap

## How do I install these formulae?

`brew install morgancrozier/tap/<formula>`

Or `brew tap morgancrozier/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "morgancrozier/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
